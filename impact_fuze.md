# Impact Fuze

## Description

Requires CC Sable.

This program will output redstone power to the bottom if there is power to the top and the computer is not moving.

## Setup

Build your bomb on a physics object. The simplest is one TNT, one computer, and one lever from top to bottom.

Run this command on the computer:

```craftos
wget run https://raw.githubusercontent.com/Iraxon/computercraft-projects/refs/heads/main/impact_fuze.lua
```

The fuze is ready for use immediately after running this command.

## Usage

1. IMPORTANT: Begin moving your vehicle.
2. Arm the bomb (input redstone signal to top of computer).
3. Drop the bomb.
4. When the bomb stops moving, it explodes.
